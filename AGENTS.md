# Agent Instructions

This repository uses project-specific context in `.ai/`.

Before making meaningful changes:

1. Read [.ai/README.md](./.ai/README.md).
2. Read [.ai/PROJECT_PHILOSOPHY.md](./.ai/PROJECT_PHILOSOPHY.md).
3. Read the task-specific context file:
   - Architecture or code work: `.ai/ARCHITECTURE.md`, `.ai/CODING_RULES.md`
   - Gameplay work: `.ai/GAME_DESIGN.md`
   - UI work: `.ai/UI_UX_RULES.md`
   - Lesson work: `.ai/CONTENT_RULES.md`, `.ai/GO_LEARNING_RULES.md`
   - Goal planning: `.ai/TASK_WORKFLOW.md`, `.ai/PROMPT_GUIDE.md`

Project rule: Go Quest is a game-first Thai learning RPG for Go. Do not turn it into a plain online course.
